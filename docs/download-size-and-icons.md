# 설치 파일 용량과 앱 아이콘

목록 조회 이후 `DownloadMetadata`와 `AppIcons`가 메타데이터를 읽습니다. 숨긴 앱은 새 메타데이터 조회 대상에서 제외합니다.

## 용량

`winget show`로 원본·ID·목표 버전을 지정해 설치 URL을 조회하고 HTTPS HEAD 응답의 Content-Length를 읽습니다. 설치 파일 본문은 받지 않습니다. 최대 3개 항목을 병렬 조회하며 성공한 응답은 12시간 캐시합니다. 설치 버전·목표 버전·원본·아키텍처·UI 언어가 캐시 키에 포함됩니다.

HEAD 거부, 크기 헤더 누락, 조회 실패는 미확인으로 표시합니다. GET으로 재시도하지 않습니다. 미확인과 0바이트는 구분합니다. 표시 단위는 KB·MB·GB이며 1,000배 단위입니다.

설치 프로그램 내부의 추가 다운로드나 의존 패키지는 포함되지 않을 수 있습니다. 따라서 설치 파일 예상 크기를 실제 총 다운로드량이나 설치 후 용량으로 표시하지 않습니다.

## 아이콘

로컬 설치 등록의 DisplayIcon과 Windows 앱 목록에서 조회합니다. 패키지 ID 우선, 고유한 정규화 이름 일치를 보조 기준으로 사용합니다. 모호하거나 누락된 경우 기본 아이콘을 표시합니다. 아이콘 경로의 프로그램을 실행하지 않습니다.

## 검증

`MetadataTests`는 URL·리디렉션 처리, HEAD 응답, 캐시, 미확인 용량, 아이콘 매칭을 모의 경계에서 검사합니다. `scripts/verify.ps1 -LiveMetadata -UseBuildHost`로 실제 읽기 전용 조회와 WPF 렌더링을 확인할 수 있습니다.
