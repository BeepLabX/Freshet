Freshet 1.0.0

요구 사항
Windows 10/11 x64, winget(앱 설치 관리자).
.NET 런타임은 EXE에 포함되어 있습니다. 현재 사용자 권한으로 실행되며,
관리자 권한이 필요한 설치 프로그램은 패키지마다 UAC 확인 창을 표시할 수 있습니다.

앱 업데이트
1. Freshet.exe를 실행하고 목록을 조회합니다.
2. 앱을 선택합니다. 목록 헤더의 체크박스는 검색 결과 중 선택 가능한 앱을 전체 선택·해제합니다.
3. ‘선택한 앱 업데이트’에서 대상과 사용 조건을 확인한 뒤 시작합니다.
중지는 현재 앱의 설치·버전 확인이 끝난 뒤 적용됩니다. 작업 후 목록을 다시 조회합니다.
‘앱 재시작 필요’는 대상 앱을 종료하고 다시 연 뒤 새로고침하세요.
‘적용 확인 안 됨’은 목표 버전을 확인하지 못한 결과입니다.
이력 행을 두 번 클릭하면 버전·결과·로그를 확인할 수 있습니다.

보류와 숨김
행의 ‘보류 ▾’에서 보류 또는 숨김을 선택합니다.
보류한 행의 ‘보류됨 ▾’에는 보류 해제와 숨김이 표시됩니다.
보류: 목록에 남지만 업데이트 선택에서 제외합니다.
숨김: 목록과 선택 합계에서 제외하며 재실행·재조회 후에도 유지합니다.
숨김 목록: 개별 또는 전체 숨김 해제. 현재 업데이트가 없는 앱도 관리할 수 있습니다.
숨김 해제는 기존 보류 상태를 유지하며 자동으로 선택하지 않습니다.
목록에 없는 앱은 새로고침한 뒤 확인합니다.
이 설정은 Freshet에만 적용되며 다른 앱의 자동 업데이트를 차단하지 않습니다.

예상 용량
설치 파일 헤더의 크기입니다. 실제 총 다운로드량·설치 후 점유 공간이 아닙니다.
추가 다운로드·의존 패키지는 포함되지 않을 수 있습니다.
미확인 값은 0으로 계산하지 않고 개수를 표시합니다.
1 KB=1,000바이트, 1 MB=1,000,000바이트, 1 GB=1,000,000,000바이트입니다.
조회 중 설치 파일 본문을 다운로드하지 않습니다. 성공한 크기 조회는 12시간 캐시합니다.
앱 아이콘은 이 PC의 설치 정보에서 읽습니다.

데이터와 백업
%LOCALAPPDATA%\Freshet\preferences.json           설정·보류·숨김
%LOCALAPPDATA%\Freshet\preferences.json.bak       직전 설정 백업
%LOCALAPPDATA%\Freshet\history\                   업데이트 이력
%LOCALAPPDATA%\Freshet\logs\                      조회·설치 로그
%LOCALAPPDATA%\Freshet\download-size-cache-v1.json 크기 캐시
설정 → 데이터 폴더 열기에서 확인합니다. 백업은 앱 종료 후 폴더를 복사합니다.
PC 간 자동 동기화는 없습니다. 조회 로그는 최근 30개만 보관합니다.

삭제
별도 Uninstall은 없습니다. 앱 종료 후 EXE 또는 압축을 푼 폴더를 삭제합니다.
이력과 설정도 지우려면 %LOCALAPPDATA%\Freshet 폴더를 삭제합니다.
Freshet으로 업데이트한 다른 앱은 그대로 유지됩니다.
서비스·자동 실행 작업·설치 등록을 만들지 않습니다.
EXE 실행 중 .NET이 만든 임시 추출 캐시는 별도로 남을 수 있습니다.

winget이 없을 때
앱 설치 관리자 설치 또는 복구 후 새로고침합니다.
원본 약관 동의가 필요하면 설정에서 약관을 확인하고 다시 조회합니다.

사용권
Pretendard의 저작권·SIL OFL 원문은 설정과 Pretendard-OFL.txt에서 확인합니다.
.NET 사용권과 외부 구성 요소 고지는 licenses 폴더에 포함합니다.
Microsoft 공식 제품이 아닙니다. 배포 EXE에는 디지털 서명이 없습니다.
화면은 Windows 앱 테마(라이트·다크)와 고대비 설정을 따릅니다.
